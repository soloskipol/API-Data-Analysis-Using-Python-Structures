# API Customer Data Analysis

## About the Project

This project uses sample customer data from an online API to explore customer information, identify patterns, and summarize useful findings. It was built to practice working with real-world data structures and learn how data can be organized for analysis.

## What the Project Does

- Retrieves customer information from an online source.
- Explores the structure of the data and extracts relevant details.
- Identifies unique cities represented in the dataset.
- Counts the number of customers in each city.
- Examines the endings of customer email addresses.
- Organizes customer information into a table for easier analysis.
- Creates a bar chart showing the distribution of customers across cities.

## Results

The project generates three files:

- **customers.csv** — contains the extracted customer information.
- **city_counts.csv** — summarizes the number of customers in each city.
- **customer_distribution.png** — visualizes the customer distribution across cities.

These outputs demonstrate how raw customer information can be organized, summarized, and presented to support basic data analysis. The findings are based on a small sample dataset and should not be treated as representative of a real customer population.

## Tools Used

- Python
- Pandas
- Matplotlib
- Requests
- Jupyter Notebook

## Data Source

[JSONPlaceholder Users API](https://jsonplaceholder.typicode.com/users)

## How to Run

1. Open the notebook in Jupyter Notebook.
2. Install the required libraries.
3. Run the notebook cells in order.
4. Open the `output` folder to view the generated files.


Through this project, I practiced retrieving data from an API, exploring nested data, using Python sets and dictionaries, organizing data into a DataFrame, and creating a chart to communicate findings.
